# 图类型

按语义内容选择布局，不要用固定模板顺序。

## 类型映射

| 内容语义 | 图类型 | 何时用 |
|---|---|---|
| 开篇主题 | 封面隐喻 | 配图组或章节以一个强概念开场 |
| 定义 | 单概念讲解 | 一个术语或概念需要展开 |
| 误解 vs 正确框架 | 左右对比 | 源内容对比两种思路 |
| 前 vs 后 | 转换对比 | 内容展示转变或升级 |
| 步骤或管线 | 横向流程 | 存在从输入到输出的序列 |
| 反馈循环 | 环形机制 | 过程随时间重复或学习 |
| 决策条件 | 分支图 | 受众需在不同情形间选择 |
| 分类 | 分类图 | 内容对概念或类型分组 |
| 多轴对比 | 矩阵表 | 选项跨维度比较 |
| 抽象系统 | 主隐喻图 | 隐喻比方框更能解释结构 |
| 警示或注意 | 批注 | 某风险需要聚焦关注 |
| 总结 | 要点 | 配图组需要一个最终记住的判断 |

## 核心图类型

### 封面隐喻

用于配图组/章节开场。

结构：

- 中等偏大中文标题
- 一个主手绘隐喻
- 可选副标题
- 可选小读者人物

仅封面图可用相对大的字号。

### 单概念讲解

用于定义与概念转折。

结构：

- 标题
- 中央概念标签
- 2–4 个支撑批注（逐字列于必需文字清单，否则不画）
- 小图标或隐喻

### 左右对比

用于错/对、旧/新、脏/净、前/后。

结构：

- 两个主组
- 轻分隔或箭头
- 左可更乱，右可更规整
- 一个小结论

### 横向流程

用于阶段、管线、执行流。

结构：

- 从左到右细线
- 4–7 个小模块
- 轻箭头
- 1–2 个批注框（框内文字逐字列于必需文字清单，否则不画）

### 环形机制

用于循环、智能体、反馈、迭代。

结构：

- 3–6 个循环阶段
- 曲线箭头
- 中心标注机制
- 边缘标注退出条件或风险

### 分支图

当决策依赖任务类型或条件时使用。

结构：

- 中央问题或决策
- 3–5 个分支
- 每个分支一句短条件与动作

### 分类图

用于框架与概念家族。

结构：

- 父概念
- 3–5 个分支
- 每分支下 1–3 个微标签

### 矩阵表

用于比较。

结构：

- 手绘网格
- 短行/列标签
- 选中格内小图标
- 边缘可选小读者人物

### 主隐喻图

用于难懂的抽象想法。

结构：

- 一个大的隐喻物体或场景
- 周围细箭头与标签
- 极少小人物

### 要点

用于最终总结。

结构：

- 一个清晰判断
- 至多 3 个呼应
- 小隐喻或图标

避免变成励志海报。

## 反模式

- 每张图都用同一布局
- 把每个想法都变成大卡片
- 每个节点旁都放人物
- 非封面图标题过大
- 整图要点列表
- 无语义功能的微小装饰元素
