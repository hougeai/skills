# 提示词模板

当需要为公众号生成最终生图提示词，或规划配图内容时使用本文件。

## 风格锁

在生成一组多张图前写一次，之后每张图的提示词复用同一套风格语言。

在生成一组多张图前，从 `references/visual-dna.md` 的『风格锁（提示词锁定）』段**原样复制**那一段逐字文本，作为每张图提示词顶部的风格锁；其精确色值 / 尺寸 / avoid 完整项以 `assets/theme-tokens.json` 为准。不要在此另写一份风格锁，避免与权威文本漂移。

## 参考匹配条款

当用户想要参考图观感或商业风格样例时使用（本技能已改为提示词锁定，不附加参考图，故仅作风格描述参考）。

```text
套用已批准的公众号插图外壳：近白暖纸、无整页边框、居中克制手写中文标题、一条淡蓝下划线、标题下小号副标题、四角极淡浅灰小圆点（规格见 theme-tokens.json 的 corner_marks）、细墨铅笔物体绘制带精致排线、小而精致的中央图解、大量留白。跨图保持外壳一致，仅按内容变动中央图解布局。
```

## 图角色锁

每张生产提示词中精确使用一种图角色。

```text
图角色：封面图。
画布：21:9 超宽，建议终稿 2520x1080。
标题可中等偏大，但仍优雅克制。
主隐喻约占页面宽 50–55%。
无页码。
```

```text
图角色：正文插图。
画布：16:9，建议终稿 1920x1080。
这不是封面页。
标题中等克制，与其余正文插图保持光学字号一致。
即便标题短，也不要放大。
中央图解约占页面宽 50–60%、高 35–45%。
```

## 完整图提示词

每张最终图用一份。作为生图提示词直接输出，不要用脚本布局替代风格试稿。

```text
用途：生产力可视化。
素材类型：一张完整中文手绘技术风插图，最终栅格图。
建议终稿尺寸：按图角色目标——21:9 封面 2520x1080 或 16:9 正文插图 1920x1080（若支持）；否则保持原生角色比例并报告实际尺寸。

图角色：<封面图 | 正文插图>
标题（精确）：<短中文标题>
副标题（精确，可选）：<短中文副标题>
图类型：<封面隐喻 | 左右对比 | 横向流程 | 环形机制 | 分支图 | 分类图 | 矩阵表 | 主隐喻图 | 要点>
核心点：<一句话>

套用风格锁：<粘贴紧凑风格锁>
套用参考匹配条款：<按需粘贴>

构图：
<基于语义的具体布局。描述物体手绘图解，而非通用方框。>
尺度锁：
<正文插图：中央图解约占页面宽 50–60%、高 35–45%；标题与其余正文插图同光学字号。>

必需文字：
<只列关键词（2–6 字），不要句子/短语/段落；解释性文字不进图。>

避免：
整页边框、黄色纸、米色纸、过大中央物体、过大正文标题、沉重底部框、多余文字、编造微标签、乱码、英文、水印、拥挤构图、过多人物、幼稚卡通、粗轮廓、饱和色、商务模板感。
```

## 紧凑三站式正文图

当内容是流程、管线或三段式框架（已批准的文章插图风格）时使用。

```text
构图：中部三个安静的站点，之间用纤细箭头连接。
每个站点上方一个淡彩标记标签，中央一个精细手绘物体。除必需文字清单中的文字外，站下及任何位置不加批注或其他文字。
物体绘制要比图标更精细：铅笔排线、细轮廓线、小结构细节。
保留宽边距与安静留白。
三站组保持紧凑：正文插图上约占页面宽 55–60%。
无整页边框。近白暖纸。仅四角极淡浅灰小圆点（规格见 theme-tokens.json 的 corner_marks）；其余纯留白。
至多一个极小人物置于右下角。
```

## 内容压缩

内部使用此提示词：

```text
把这段源内容压缩成一张图。
只保留一个核心点。
选择最合适的语义图类型。
返回标题、2–4 个内容块、可选批注、必需可见文字，以及一份完整图提示词简报。
不要产出要点堆。
```

## 多图一致性检查

生成提示词前检查：

```text
- 每张图是否共享同一外壳（近白纸、无边框、标题下划线、线宽、淡彩家族）？
- 封面是否 21:9、正文插图是否 16:9？
- 正文插图标题光学字号是否一致，含短标题？
- 中央图解是否足够紧凑，模型有没有把页面填满？
- 布局是否按语义而非随机不同？
- 整组图人物是否过多？
- 每张图的「必需文字」列表是否足够短以便干净渲染？
- 道具是否不含假英文、网址与填充文字？
```

## 文字保真兜底

仅当视觉方向已接受、但生图中文仍不准时使用。

```text
重新生成或复用已接受的视觉，为每个精确中文标签预留空白位。
不要编造任何占位文字。
在文字将叠加处保留干净的淡彩标签或空白纸面。
生成后，仅用确定性本地后处理补上「必需文字」项，尽量贴近小硬笔中文标题/正文字体。
复查确认没有重复、假造或拼错的生成文字残留。
```
