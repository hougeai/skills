# GZH Handdrawn

典型用法：先按文章规划配图方案（含配图清单），再逐张写出提示词。

## Operating Rule

本技能只产出生图提示词，不直接出图（由宿主 img_gen 渲染）。统一手绘锁定风格：精确数值（纸调色值/画布尺寸/avoid 清单/图类型枚举）以 `assets/theme-tokens.json` 为准，风格锁的逐字可粘贴文本取自 `references/visual-dna.md` 的『风格锁（提示词锁定）』段、原样复用，不附加参考图。图内中文极简：只放关键词，句子/段落交给文章正文，不进图。

## Resource Map

按需加载，不要一次塞满：

- `references/intake.md`：输入类型、缺失信息检查、精简澄清规则。
- `references/narrative-planning.md`：文章视觉类型选择与叙事结构。
- `references/image-archetypes.md`：内容类型到图布局的语义映射。
- `references/visual-dna.md`：视觉系统权威说明，含**逐字可粘贴的风格锁文本**与字体/颜色/线条等完整规范。
- `references/output-quality.md`：成图的输出契约与验收门槛。
- `references/prompt-patterns.md`：提示词模板与组装骨架（风格锁从 visual-dna.md 粘贴，数值以 tokens 为准）。

写提示词时：精确数值（色值/尺寸/avoid/图类型枚举）以 `assets/theme-tokens.json` 为准；风格锁的逐字可粘贴文本取自 `references/visual-dna.md` 的『风格锁（提示词锁定）』段、原样复用，不附加参考图。

## Workflow

1. **摄入素材**：输入为纯文本、Markdown、笔记或大纲时直接解析；

2. **缺口诊断**
   - 当内容宽泛、不完整或输出要求不明时，读 `references/intake.md`。
   - 确定主题、受众、场景、目标篇幅与素材充分度。
   - 仅当缺失信息会实质改变成图方案时，最多问 1-3 个问题；否则用合理默认继续。

3. **规划文章视觉叙事**
   - 读 `references/narrative-planning.md`。
   - 将文章视觉归类为教学、说服、报道、产品讲解或知识卡风格。
   - 逐图规划主线：每张图只讲一个核心点。

4. **为每张图映射图类型**
   - 读 `references/image-archetypes.md`。
   - 按内容语义选布局，而非固定模板顺序。
   - 变换图类型，让整组图有节奏。

5. **应用视觉 DNA**
   - 读 `references/visual-dna.md`：视觉系统的权威设计说明，内含**逐字可粘贴的风格锁文本**（『风格锁（提示词锁定）』段），以及字体 / 颜色 / 线条 / 人物等完整规范。
   - 读 `assets/theme-tokens.json`：风格锁的**结构化数值源**（精确色值、画布尺寸、avoid 清单、图类型枚举）；粘贴风格锁时以其中数值为准。
   - 公众号视觉默认两种角色：21:9 封面图与 16:9 正文插图（数值见 tokens）；不要让正文插图看起来像封面。

6. **产出提示词**
   - 仅规划时，交付结构化蓝图：类型、图数量、标题、核心点、图类型、内容块、视觉简报、缺失输入。
   - 生产时，为每张图直接输出一份独立提示词（不套用通用重复模板），交宿主 img_gen 渲染。
   - 封面按 21:9、正文插图按 16:9（除非用户另指定）。
   - 生成多张前，从 visual-dna.md 复制同一份风格锁文本，原样复用在每张图提示词顶部；仅中央图解/内容区加图特定布局指令。
   - 所有可见中文在提示词中只放 2–6 字关键词，不要句子/短语/段落；解释性文字不进图，每张图附 `必需文字` 清单。
   - 若中文关键或易错，提示词中要求预留空白标签位，由 img_gen 渲染后做精确文字叠加。

7. **验收提示词**
   - 读 `references/output-quality.md`。
   - 检查内容准确性、图组节奏、必需文字 是否够短、风格锁是否一致、是否误含 PPT 框架词。
   - 验收不通过则修订后再交付。

## Defaults

除非用户另有说明：

- 语言：简体中文。
- 受众：有一定技术好奇心但不一定深入的国内读者。
- 配图数量：单篇文章 4-8 张（含 1 封面 + 若干正文插图），长文不超过 9 张，短文 1-3 张。
- 产出：提示词（直接输出）+ 简短配图方案摘要。
- 公众号视觉拆分：封面 21:9；正文插图 16:9。
- 风格：精致近白手绘中文公众号插图。

## Final Response

直接逐张输出可贴入 img_gen 的中文提示词（含 必需文字 与风格锁明文）。
仅规划时，先给配图方案蓝图（图数量 / 类型 / 插入位置 / 核心点），再逐张出提示词。
